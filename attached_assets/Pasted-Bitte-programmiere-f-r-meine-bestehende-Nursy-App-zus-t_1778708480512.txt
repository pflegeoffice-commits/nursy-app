Bitte programmiere für meine bestehende Nursy-App zusätzliche Pflegeplanungs-Vorlagen.

Wichtig:
Die bestehende Struktur darf NICHT verändert werden.

NICHT ändern:
- keine neuen Tabs
- keine neuen Spalten
- kein neues Layout
- keine neue Pflegeplanungsverwaltung
- keine Änderung an Buttons
- keine Änderung an bestehenden Funktionen
- keine Pflegestufe/Pflegegrad ergänzen

Es sollen ausschließlich neue Datensätze in die bestehende Vorlagenliste eingefügt werden.

Die bestehende Tabelle besteht aus:
- Symptome
- Maßnahme
- Ziel

Bitte ergänze mindestens 150 neue Pflegeplanungs-Vorlagen für die gesamte Pflege.

Jeder Eintrag muss genau diese Struktur haben:

{
  symptom: "...",
  massnahme: "...",
  ziel: "..."
}

Falls der bestehende Code andere Feldnamen verwendet, verwende bitte exakt die vorhandenen Feldnamen aus dem Projekt, z. B.:
- symptome statt symptom
- maßnahme oder massnahme
- ziel

Bitte die neuen Vorlagen direkt in das bestehende Array der Pflegeplanungs-Vorlagen einfügen.

Formulierungsregeln:
- kurz und klar
- praxisnah
- für Pflegekräfte im Alltag geeignet
- keine langen theoretischen Texte
- keine medizinischen Diagnosen als Hauptfokus
- immer pflegerisch formulieren
- Maßnahmen nur im Rahmen der Qualifikation, ärztlichen Anordnung und österreichischen Pflegepraxis formulieren

Beispiele für Stil:

{
  symptom: "Infusionszugang vorhanden / Infektionsrisiko",
  massnahme: "Einstichstelle kontrollieren, Verband sauber und trocken halten, hygienisch arbeiten, Auffälligkeiten dokumentieren und weiterleiten",
  ziel: "Keine Infektionszeichen, Zugang bleibt komplikationslos nutzbar"
}

{
  symptom: "Eingeschränkte Mobilität",
  massnahme: "Mobilisation nach Ressourcen unterstützen, Hilfsmittel bereitstellen, sichere Umgebung schaffen",
  ziel: "Mobilität wird erhalten und Sturzrisiko reduziert"
}

{
  symptom: "Unterstützungsbedarf bei der Körperpflege",
  massnahme: "Körperpflege teilweise oder vollständig unterstützen, Ressourcen fördern, Hautzustand beobachten",
  ziel: "Körperpflege ist sichergestellt und Selbstständigkeit bleibt erhalten"
