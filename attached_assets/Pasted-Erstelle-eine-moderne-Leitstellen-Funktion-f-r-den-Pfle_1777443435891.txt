Erstelle eine moderne Leitstellen-Funktion für den Pflegenotdienst akut plus als Frontend-Web-App mit HTML, CSS und JavaScript.

Design:
- Professionell, modern, übersichtlich
- Hauptfarbe Dunkelblau
- Akzentfarben Weiß, Hellgrau, Türkis/Blau
- Buttons im einheitlichen Pill-Style
- Buttons ca. 48px Höhe
- Stark abgerundete Karten und Eingabefelder
- Responsives Layout für Desktop, Tablet und Smartphone
- Serifenbetonte Zeitungsschrift für Überschriften
- Gute Lesbarkeit für Leitstellenbetrieb

Ziel:
Es soll ein professionelles Alarmierungsformular für eine Pflege-Leitstelle entstehen. Die Leitstelle soll Einsätze erfassen, Patienten suchen, gespeicherte Daten übernehmen, pflegerische Ersteinschätzungen dokumentieren und eine Einsatzentscheidung vorbereiten können.

--------------------------------------------------
1. Patientensuche / gespeicherte Daten
--------------------------------------------------

Ganz oben im Formular soll eine Suchfunktion stehen:

Label:
„Patient im System suchen“

Placeholder:
„Name, SV-Nummer oder Telefonnummer eingeben...“

Funktion:
- Live-Suche mit Autocomplete
- Suche nach Nachname, Vorname, Sozialversicherungsnummer und Telefonnummer
- Ergebnisse als Dropdown-Karten anzeigen

Pro Suchergebnis anzeigen:
- Nachname Vorname
- Geburtsdatum
- Wohnort
- Sozialversicherungsnummer gekürzt, z. B. **** 120599
- Telefonnummer

Beim Klick auf einen Patienten sollen automatisch folgende Felder ausgefüllt werden:
- Nachname
- Vorname
- Sozialversicherungsnummer
- Geburtsdatum
- Straße
- Hausnummer
- Stock
- Tür
- PLZ
- Wohnort
- Bezirk
- Telefonnummer Patient
- E-Mail Patient
- Angehörige
- bekannte Erkrankungen
- Allergien
- wichtige medizinische Informationen

Zusätzliche Buttons:
- „Neuen Patienten anlegen“
  - leert alle patientenbezogenen Felder
- „Daten aktualisieren“
  - speichert Änderungen in LocalStorage
- „Patient speichern“
  - speichert neuen Patienten in LocalStorage

Technik:
- Verwende JavaScript LocalStorage als Demo-Datenbank
- Lege mindestens 3 Beispielpatienten an
- Wenn LocalStorage leer ist, sollen die Beispielpatienten automatisch geladen werden

- Geburtsdatum
- Straße
- Hausnummer
- Stock
- Tür
- PLZ

Sozialversicherungsnummer:
- Label: Sozialversicherungsnummer
- Placeholder: z. B. 1234 TTMMJJ
- Hinweistext: „Bitte österreichische Sozialversicherungsnummer inkl. Geburtsdatum eingeben.“

PLZ / Bezirk:
- Das Feld „Bezirk“ soll automatisch anhand der österreichischen PLZ ermittelt werden
- Verwende eine JavaScript-Mapping-Funktion mit Beispielen für Oberösterreich, Salzburg, Wien und Niederösterreich
- Wenn keine PLZ erkannt wird: „Bezirk unbekannt“
- Bei Änderung der PLZ soll der Bezirk automatisch aktualisiert werden

--------------------------------------------------
12. Technische Anforderungen
--------------------------------------------------

- Nur HTML, CSS und JavaScript
- Keine Backend-Abhängigkeit
- LocalStorage für Patienten und gespeicherte Einsätze
- Saubere Dateistruktur:
  - index.html
  - style.css
  - script.js
- Der Code soll vollständig lauffähig sein
- Alle Formularelemente brauchen eindeutige IDs
- Checkboxen sollen sauber gruppiert sein
- Dynamische Felder sollen nur erscheinen, wenn die passende Checkbox oder Auswahl aktiv ist
- Formular soll optisch wie professionelle Leitstellen-Software wirken
- Keine Platzhalter-App, sondern vollständig funktionsfähige Demo
